Cookie Tutorial

How to find your cf_clearance value on phone or PC, one step at a time.

▯ Phone Android ↓▱ PC Desktop ↓
Before you start

You only need the raw value after cf_clearance=. Stop at the next ; or the end of the string. Keep your full cookie string private.

01 / PHONEEasiest · No ZIP needed

Firefox for Android

Option A · Use the Cookie-Editor add-on.

  1. Open Firefox on your phone.
  2. Go to discord.com/app ↗ and log in.
  3. Tap the ⋮ menu (top-right), then Add-ons (called Extensions in some versions).
  4. Search for Cookie-Editor.
  5. Select Cookie-Editor by cgagnier, then tap Add to Firefox.
  6. Go back to discord.com.
  7. Open the Cookie-Editor add-on from Firefox’s menu.
  8. Tap Export at the top of the popup.
  9. Choose Header String to copy the full cookie string to your clipboard.
  10. Paste it into a private local note so you can inspect it.
  11. Find cf_clearance= in the string.
  12. Select only the value after cf_clearance=. Stop before the next ; or the end of the string.
  13. Copy just that value.

This phone method is for Android. Using another Android browser? See Option B below. Firefox on iPhone does not support this add-on; use a PC instead.

OPTION B / PHONE

Chromium-based browsers

Kiwi / Edge / Vivaldi / Quetta / Yandex

Use this ZIP method in browser versions that offer Developer mode and Load unpacked. Extension support and menu names vary. If those controls are missing, use the browser’s supported extension store or Option A: Firefox for Android.

Step 1: Download the ZIP

  1. Open the official Cookie-Editor releases ↗.
  2. Open the latest release’s Assets and download the Chrome extension ZIP. Version 1.13.0 lists cookie-editor-chrome-1.13.0.zip.
  3. Unzip it using your file manager or ZArchiver. Keep the extracted folder.

Downloaded as .txt? If it is the extension ZIP with the wrong filename, rename the extension to .zip before extracting.

Step 2: Enable Developer mode

Open your browser’s extension management page. Where supported, type the corresponding address below, then switch Developer mode on.

Extension management addresses
BrowserType in the address bar
Kiwichrome://extensions
Edgeedge://extensions
Vivaldivivaldi://extensions
Quettachrome://extensions
Yandexchrome://extensions

Step 3: Load the extension

  1. Tap Load unpacked.
  2. Select the extracted extension folder containing manifest.json.
  3. Open the Extensions menu (puzzle-piece icon) and pin Cookie-Editor if your browser offers pinning.

Step 4: Get cf_clearance

  1. Go to discord.com/app ↗ and log in.
  2. Open Cookie-Editor.
  3. Tap Export.
  4. Choose Header String to copy the full cookie string.
  5. Paste it into a private local note.
  6. Find cf_clearance= and select only the value after it. Stop before the next ; or the end of the string.
  7. Copy just that value.

× No cf_clearance= prefix

× No other cookies or ; separators

✓ Raw value only

For Vivaldi, see the official Android extension installation guide ↗.

02 / PC

PC

Chrome / Edge / Firefox / Brave / Vivaldi

  1. Go to discord.com/app ↗ and log in.
  2. Press F12 or Ctrl + Shift + I to open developer tools.
  3. Click the Network tab.
  4. In the filter box, type /api.
  5. Refresh with F5, or open and close a channel.
  6. Click a discord.com API request in the list.
  7. In the right panel, open Headers → Request Headers.
  8. Find the Cookie: line.
  9. Find cf_clearance= in that line. Select only the part after the =, up to the next ; or the end of the string.
  10. Copy the value.
THE FINAL CHECK

What to paste

✓ Just the raw value

3XIxX5zt0hqeBFvNTld2HZUi9J1AkvfKZaf26B4XwIg-1792663267-1.2.1.1-DDjfXVa...

× Not the full cookie string

cf_clearance=3XIxX5zt...; _cfuvid=abc123; __dcfduid=xyz

Illustrative examples only. Do not include cf_clearance=, other cookies, or ; separators.

Can’t find it?

The cookie may not be present in every browser session. If it is missing, there is no value to copy. Check that you’re inspecting a request to discord.com.
