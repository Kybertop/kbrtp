Cookie Tutorial

How to find your cf_clearance value on phone or PC, one step at a time.

▯ Phone Android ↓▱ PC Desktop ↓
Before you start

You only need the raw value after cf_clearance=. Stop at the next ; or the end of the string. Keep your full cookie string private.

01 / PHONEEasiest · No ZIP needed

Firefox for Android

Option A · Use the Cookie-Editor add-on.

  1. Open Firefox on your phone.
  2. Go to discord.com/app ↗ and log in.
  3. Tap the ⋮ menu (top-right), then Add-ons (called Extensions in some versions).
  4. Search for Cookie-Editor.
  5. Select Cookie-Editor by cgagnier, then tap Add to Firefox.
  6. Go back to discord.com.
  7. Open the Cookie-Editor add-on from Firefox’s menu.
  8. Tap Export at the top of the popup.
  9. Choose Header String to copy the full cookie string to your clipboard.
  10. Paste it into a private local note so you can inspect it.
  11. Find cf_clearance= in the string.
  12. Select only the value after cf_clearance=. Stop before the next ; or the end of the string.
  13. Copy just that value.

This phone method is for Android. Firefox on iPhone does not support this add-on; use a PC instead.

02 / PC

PC

Chrome / Edge / Firefox / Brave / Vivaldi

  1. Go to discord.com/app ↗ and log in.
  2. Press F12 or Ctrl + Shift + I to open developer tools.
  3. Click the Network tab.
  4. In the filter box, type /api.
  5. Refresh with F5, or open and close a channel.
  6. Click a discord.com API request in the list.
  7. In the right panel, open Headers → Request Headers.
  8. Find the Cookie: line.
  9. Find cf_clearance= in that line. Select only the part after the =, up to the next ; or the end of the string.
  10. Copy the value.
THE FINAL CHECK

What to paste

✓ Just the raw value

3XIxX5zt0hqeBFvNTld2HZUi9J1AkvfKZaf26B4XwIg-1792663267-1.2.1.1-DDjfXVa...

× Not the full cookie string

cf_clearance=3XIxX5zt...; _cfuvid=abc123; __dcfduid=xyz

Illustrative examples only. Do not include cf_clearance=, other cookies, or ; separators.

Can’t find it?

The cookie may not be present in every browser session. If it is missing, there is no value to copy. Check that you’re inspecting a request to discord.com.
