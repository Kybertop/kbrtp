04 / QUICK ANSWERS

FAQ & troubleshooting

Why aren’t my stats counting?

First check the community’s recommended data settings:

  1. Open Discord User Settings ⚙️ → Data & Privacy (or Privacy & Safety).
  2. Find How We Use Your Data.
  3. Check Use data to personalize my Discord experience and Use data to improve Discord.

The community guide recommends enabling both. These settings allow additional data use; Discord’s documentation does not confirm they guarantee spoofed badge progress. Data privacy controls ↗

Do I need Python first?

Yes. Install Python 3.10 or newer before running spoofer.py. Download Python ↗

How long until badges or stats appear?

The community FAQ reports 24–72 hours. Updates are not instant, and an accepted request does not guarantee that Discord awards a badge.

Does it actually work? Is it still working?

The project reports success by submitting game-launch and heartbeat events. Current results can change when Discord updates. Check the repository and support server for updates.

Does it work on mobile?

The community reports Android support using a Python environment. Ask in Discord support ↗ for the “Run Spoofer.py on Android” guide. Fingerprint generation is Windows-only.

Where do I get my Discord token?

Use the Token Tutorial ↗. Never share the token or your science_state.json file.

Where do I get the cf_clearance cookie?

Follow the Cookie Tutorial ↗. Paste the full cookie string into the script’s cookie prompt, including cf_clearance=. Leave out the Cookie: label.

Do I need a new cookie every time?

Not necessarily. Refresh it when it expires or requests are rejected. Lifetime can vary; the community reports roughly an hour. Select 2 · Refresh auth to update it.

Should I change my password afterward?

If your token or state file was exposed, reset your Discord password. Being open source does not guarantee a script is safe. Discord security guidance ↗

“Fingerprint not set” — is it broken?

The script can continue without it, but badge credit is not guaranteed. If needed, use 3 · Set fingerprint on Windows with a game’s .exe path or process ID.

Do I need to keep my PC or script running?

Keep it open until processing completes. Once all batches finish, you can close the window; waiting for badge updates does not require keeping the script open.

Is it safe?

It is open source, but that does not prove it is free of malicious code or account risk. It stores credentials locally and makes network requests. Review the code before using it; the project warns it violates Discord’s terms.

I got a 401 or 403 error. Did earlier batches save?

Batches marked sent were accepted by the endpoint; badge credit is a separate step. Use 2 · Refresh auth with a fresh cookie. If 401 persists, check your token.

How do I switch accounts or fix a wrong token?

Close the script, remove science_state.json, then restart it. It will ask for fresh credentials. This also resets locally saved progress and setup flags.

What numbers should I enter?

The community FAQ suggests 250–500 games and 50–100 hours per game. These are community suggestions, not verified safe limits or a guarantee of results.

Can it spoof streaming hours?

No. This script handles game activity, not streaming hours.
