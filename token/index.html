Discord / Token guide

Token Tutorial

Two methods for viewing your own Discord account token. Choose your device to get started.

PC Console ↓PC & Mobile Bookmarklet ↓
Keep it private

Your token can grant access to your account. Treat it like a password. Use these steps only with your own account, and never send the token to a website, DM, or “free Nitro” service. This page has no token input.

01 / PC BROWSER ONLY

Developer Console

Windows / Linux · Chrome, Edge, or Firefox

  1. Open Chrome (or Edge / Firefox) and go to discord.com/app ↗.
  2. Log in to your account and wait for Discord to fully load.
  3. Press F12 or Ctrl + Shift + I to open DevTools.
  4. Click the Console tab at the top.
  5. Read any console security warning before continuing. Only run code you understand and have reviewed.
  6. Click inside the console input area, on the line with >.
  7. Copy the entire script below and paste it into the console.
  8. Press Enter.
  9. If found, a prompt labelled Token: appears. Focus the text field, then use Ctrl + A and Ctrl + C to select and copy the token.

macOS

Follow the same steps, using ⌘ + Option + I to open DevTools. Use ⌘ + A and ⌘ + C to copy.

The script uses Discord’s internal web app modules. Updates to Discord may prevent it from finding a token; this is not an official Discord API.

02 / PC & MOBILE

Bookmarklet

Save the same script as a bookmark, then run it while on Discord. Mobile support varies by browser and version.

Creating the bookmarklet on PC

Chrome / Edge

  1. Go to discord.com/app and log in.
  2. Click the star icon ☆ in the address bar to bookmark the page.
  3. Click Done, then find the saved bookmark and choose Edit.
  4. Delete everything in the URL field and paste the complete script above, beginning with javascript:.
  5. Change the Name to DT.
  6. Click Save.

Creating the bookmarklet on mobile

Chrome / Samsung Internet / Safari · Menu labels vary.

  1. Go to discord.com and log in.
  2. Bookmark the page. In Chrome, open ⋮ → Add to bookmarks. In Safari, use Share → Add Bookmark.
  3. Open your bookmarks, find the new bookmark, and tap Edit or the pencil icon.
  4. Delete the entire URL and paste the same javascript: string from the script above.
  5. Change the title or name to DT.
  6. Tap Done or Save.

Running it on PC

  1. Make sure you are logged in on discord.com.
  2. Click DT in your bookmarks bar or Bookmarks menu.
  3. If the script finds your token, the Token: prompt appears.

Running it on mobile

Brave / Kiwi / Samsung Internet / Safari and other browsers

  1. Keep the logged-in discord.com page open.
  2. Open the Bookmarks list and tap DT.
  3. If supported by the browser and current Discord app, a prompt appears with your token.

Chrome on mobile

  1. Make sure you are on discord.com and logged in.
  2. Try opening the Bookmarks list and tapping DT.
  3. If nothing happens, tap the address bar, start typing DT, and select the saved bookmark suggestion.

If a browser opens a blank page or does nothing, the bookmarklet may not be supported in that context. Do not paste the script directly into the address bar; use the saved bookmark.

NEED A HAND?

Troubleshooting

“Not found” alert
Make sure you are logged in and Discord has fully loaded. If it still fails, Discord’s internal code may have changed.
Nothing happens on mobile
Try the saved bookmark suggestion in the address bar. Browser restrictions may prevent bookmarklets from running.
The browser blocks javascript: in the address bar
Edit the saved bookmark’s URL and run the bookmark instead of pasting the script directly into the address bar.
The token is blank or too short
Your session may have expired. Log in again and retry.
If your token is compromised

Reset your Discord password immediately to generate a new token, enable two-factor authentication, and remove unfamiliar apps under User Settings → Authorized Apps. Deauthorizing apps alone is not a substitute for resetting a leaked account token. Discord’s security guidance ↗
